# V14 · CAM1 Master + PRISM Screencast

Arquitectura de cuatro teléfonos:

1. CAM1 Master + PRISM Screencast + Overlay + Facebook.
2. CAM2 remota.
3. CAM3 remota.
4. Director / Switcher.

CAM1 Master captura la cámara del teléfono, envía una copia ligera al Director, recibe CAM2/CAM3, ejecuta cambios, replay, stinger, overlay y videos externos. PRISM transmite la pantalla mediante Screencast.

## Orden de inicio

1. Abrir CAM2 y CAM3.
2. Abrir Director.
3. Abrir CAM1 Master en Chrome, autorizar permisos y pulsar INICIAR.
4. En PRISM elegir Screen/Screencast, iniciar emisión y regresar a CAM1 Master.
5. Mantener el teléfono horizontal, sin bloquear pantalla.
