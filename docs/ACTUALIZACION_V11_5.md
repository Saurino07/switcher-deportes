# V14 — Stinger de Replay y Multimedia Externa

- Transición profesional antes/después de Replay por deporte.
- Presets ligeros incluidos para béisbol, fútbol, básquetbol, fútbol americano y genérico.
- URL personalizada para PNG, JPG, SVG, GIF, MP4 o WebM.
- Panel para enviar videos externos al overlay mediante URL pública directa.
- Compatibilidad retroactiva con `assets/archivo.mp4` y `videos/archivo.mp4`.
- No es necesario subir videos pesados al repositorio de GitHub.
