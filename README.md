# Switcher Deportivo V15.3 Broadcast UI

Corrección integral del arranque de CAM1 Master y selección de cámaras.

## CAM1 Master
1. Abre la URL completa con `game`, `v=1530` y `code`.
2. Elige **Cámara trasera** o **Cámara frontal**.
3. Pulsa **INICIAR CAM1 MASTER**.
4. Después del permiso, la lista **Cámara detectada** mostrará los dispositivos reales.
5. Para cambiar, selecciona otra orientación o dispositivo y pulsa **CAMBIAR CÁMARA**.

Si Android indica que la cámara está ocupada, cierra PRISM antes de iniciar CAM1 Master. Después inicia PRISM Screencast y vuelve a la aplicación.
